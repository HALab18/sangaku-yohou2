# PeakWeather — 山頂コンディションをもっと手軽に。

v2 — 「天気で山さがし」（横断検索）機能を追加

山の名前を入れるだけで、**山頂・稜線の気象予報**（稜線の風・山頂気温・体感温度・
降水・発雷リスク・景色（眺望）の見込み・登山指数）を表にして返すツールです。

## 🌐 Webアプリ版（インストール不要）

**https://halab18.github.io/sangaku-yohou2/**

ブラウザで開いて山名を入れるだけ。スマホ対応、Python不要です。
検索結果のURL（`#燕岳/2026-07-19` のような形式）はそのまま共有できます。
山名のほか、**GPS現在地**（「現在地の予報を見る」ボタン）、**緯度経度を直接指定**
（[座標を指定して予報を取得](https://halab18.github.io/sangaku-yohou2/docs/point.html)。
国土地理院「地理院地図」等で調べた座標に対応）でも予報を取得できます。

**圏外対応**: 表示した予報は端末内に自動保存され（直近3座／予報冒頭の「圏外用に固定」を
押した山はさらに3座）、電波の無い場所で同じ山を検索すると「📴 オフライン表示」の断りつきで
再表示されます。アプリの画面自体も Service Worker で保持するため、一度開いた端末なら
圏外でも起動できます。

## 特徴

- **山頂の高さの予報**: 麓の天気予報ではなく、山頂標高を指定して気温・風を取得
- **稜線風**: 地上10m風ではなく、上空の気圧面（850/800/700hPa等）の風を山頂標高で補間。
  「麓は風速2mでも稜線は15m」がちゃんと数字で出ます
- **登山指数 A/B/C**: **稜線風速と降水量**で主判定し、低体温・体感温度・視界の降格条件を安全側にのみ重ねる（最悪値採用）。
  夏山（6〜10月）と冬山・残雪期（11〜5月）で閾値を自動切替。
  17〜20時に急変（C相当）または雷が予想される日は「⚠夕方」、
  夜間（21時〜翌5時）にC相当が予想される日は「⚠夜間」を付記。
  雷・体感温度・景色は指数に混ぜず、それぞれ独立した情報として表示する設計
- **⚡発雷リスク**: CAPE（燃料）と CIN（蓋）から4段階（低/やや注意/注意/高い）。指数には非反映
- **🏔 景色（眺望）◎/○/△/✕**: 山頂付近の雲・視程・降水を組み合わせて判定。雲海チャンスも検出。
  視程は判定の内部要素として使い、景色欄に補足併記（独立した視程列は設けない）
- **直近3日の実況(モデル解析値)**: 直近の降水・降雪・積雪の経過を表示。
  登山道の状態(ぬかるみ・増水・残雪)を見立てる材料に
- **積雪深・新雪の表示**: 雪のある期間は各表に「積雪max(新雪)」列を自動追加（夏山では非表示）
- **内蔵山岳DB 604座**: 日本百名山・二百名山・三百名山・東北百名山ほか各地の人気の山。国土地理院・yamarecoの
  地名/標高データで座標を照合済み。DBにない山も地名検索で自動解決、緯度経度の直接指定も可
- **10日先までの見通し** と **確度**（気象庁/ECMWF/GFS の3モデルに同じ判定手順を回し、指数が
  どれだけ揃うかを ◎○△ で併記。実測で3日前時点の的中率は ◎77%/○43%/△26%。判定には使わない）
- **日本域に最適化された気象庁モデル**（前半=MSM 約5km / 後半=GSM へ自動切替。切替日はモデルの
  更新時刻で前後するため決め打ちにせず、出力の「全球」印で実際の境目を示す）が基本データ源。
  同モデルに無い項目（降水確率・突風・CAPE/CIN・視程・積雪深）のみ汎用モデルから補完
- **HTMLレポート出力**: 色分きの単一HTMLで保存、スマホでもそのまま見られる
- **依存ゼロ**: Python 3 標準ライブラリのみ。APIキー・アカウント登録不要

仕組みの詳しい解説（図解入り・非エンジニア向け）:

## インストール

```
git clone https://github.com/HALab18/sangaku-yohou2.git
cd sangaku-yohou2
python scripts/mountain_weather.py --name 富士山
```

gitがない場合は GitHub の「Code → Download ZIP」で展開しても同じです。
`scripts/` と `references/` は同じフォルダ直下に置いたまま使ってください（スクリプトが相対参照）。

## 使い方

```
# 基本: 直近実況 + 10日間の見通し(確度つき) + 今日から4日分の詳細 をまとめて表示
python scripts/mountain_weather.py --name 燕岳

# 詳細表示の開始日を指定（例: 週末から4日分）
python scripts/mountain_weather.py --name 天狗岳 --date 2026-07-18

# 詳細を1時間ごとに表示（既定は3時間ごと）
python scripts/mountain_weather.py --name 谷川岳 --interval 1

# HTMLレポートを保存してブラウザで開く
python scripts/mountain_weather.py --name 燕岳 --html --open

# DBにない山・任意の地点（--elev は山頂標高）
python scripts/mountain_weather.py --lat 36.407 --lon 137.713 --elev 2763 --label 燕岳
```

| オプション | 意味 |
|---|---|
| `--name 山名` | 山名で指定（内蔵DB→地名検索の順で解決） |
| `--select N` | 同名の山が複数あるとき候補一覧から番号で選択 |
| `--date YYYY-MM-DD` | 詳細表示の開始日（省略時は今日から4日分） |
| `--interval 1` | 詳細を1時間ごとに表示（既定は3時間ごと） |
| `--html [PATH]` | HTMLレポート保存（PATH省略時は自動命名） |
| `--open` | 保存したHTMLをブラウザで開く |
| `--lat --lon --elev --label` | 座標で直接指定 |

同名の山（例: 「大山」= 鳥取／丹沢）は候補が表示されるので `--select 1` のように選び直してください。

## 出力の読み方

- **登山指数**: A=登山適 / B=要注意（経験者向き・行程短縮検討） / C=登山不適。
  主判定は**稜線風速と降水量**、これに降格条件（低体温=気温10℃以下+降水+風8m/s以上 /
  体感=体感温度-20℃以下 / 視界=視程200m未満+風10m/s以上）を安全側にのみ重ねる。
  行動時間帯（5〜16時）の最悪値。夏冬の切替は月＋その日の山頂気温。
  境目は季節で自動切替:
  夏山（6〜10月）=稜線風10/15m/s・3時間降水1/5mm、
  冬山・残雪期（11〜5月）=稜線風8/12m/s・3時間降水1/3mm。
  降水確率・雷（CAPE）は判定に使わず参考表示のみ。詳細は
  [references/criteria.md](references/criteria.md)
- **⚠夕方**: 17〜20時にC相当の急変、または発雷リスクが「高い」、
  あるいは「注意」以上かつ同じ時間帯の降水量合計が1.0mm以上と予想される印。
  日中の指数には含まれないので、
  下山遅れ・テント泊の場合は詳細表で夕方以降を確認してください
- **⚠夜間**: 当日21時〜翌朝5時に風・降水でC相当が予想される印。
  テント泊・小屋泊で夜間の荒天に当たるかの材料（日中の指数には含まれません）
- **体感温度**: Apparent Temperature（Steadman）。気温・風・湿度から算出し、全温度域で有効。
  濡れるとさらに下がります
- **直近の実況**: 過去3日のモデル解析値（観測所の実測ではない）。登山道のぬかるみ・増水・
  残雪を推定する材料。実際の状況は山小屋等の現地情報を優先してください
- **積雪max(新雪)**: 「85cm(+12)」= 積雪深max 85cm・その日の新雪12cm。
  期間内に雪が無ければ列ごと非表示
- **🏔 景色(朝)**: 4〜8時の最良値。ご来光・朝焼けの目安。「◎ 展望良好(雲海)」は雲海チャンス。
  括弧内の視程は、その判定に使った時刻の値
- **⚡発雷リスク**: CAPE（燃料）と CIN（蓋）から4段階。夏山で午後に「注意」以上が並ぶ日は
  「早出早着・13時までに樹林帯へ」

## Claude Code スキル連携（任意）

[Claude Code](https://claude.com/claude-code) を使っている場合、「◯◯岳の予報を調べて」と
話しかけるだけでこのツールが自動実行され、AIが表の読み解き付きで答えるようにできます。

1. `skill/SKILL.md` を `~/.claude/skills/sangaku-yohou/SKILL.md` にコピー
   （Windows: `C:\Users\<ユーザー名>\.claude\skills\sangaku-yohou\SKILL.md`）
2. コピーしたファイル内の `{{REPO_PATH}}` をクローン先の絶対パス（例: `D:\dev\sangaku-yohou`）に一括置換

数値の取得・計算はすべて本スクリプト（決定的なコード）が行い、AIは解説だけを担当します。

## 山岳DBのメンテナンス

内蔵DB（`references/mountains.csv`）を編集・追加した場合は、健全性チェックを実行してください:

```
python scripts/check_mountains.py
```

CSVの形式、Webアプリ版（index.html）内蔵DBとの同期、Open-Meteo Elevation APIによる
標高の照合（座標が山頂から大きく外れていないか）を一括検証します。

## トラブルシューティング

- **証明書エラー（CERTIFICATE_VERIFY_FAILED）**: SSL検査を行う社内ネットワークで発生します。
  ネットワーク管理者に確認するか、自宅回線で実行してください
- **プロキシ環境**: 環境変数 `HTTPS_PROXY` を設定してください
- **文字化け**: 出力はUTF-8です。Windowsのコマンドプロンプトでは `chcp 65001` を実行するか、
  PowerShell 7 / Windows Terminal の利用を推奨
